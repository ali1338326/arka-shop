# آرکا — فروشگاه آنلاین

فروشگاه نمایشی محصولات طراحی و سبک زندگی با پشتیبانی کامل از فارسی و RTL.

## امکانات
- سبد خرید با ذخیره‌سازی در مرورگر
- فیلتر و مرتب‌سازی محصولات
- جست‌وجوی زنده
- علاقه‌مندی‌ها
- فرآیند پرداخت سه‌مرحله‌ای
- حالت تاریک/روشن
- طراحی واکنش‌گرا

## تکنولوژی
HTML + CSS + JavaScript (بدون Build، بدون وابستگی)
